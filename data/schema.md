# 物理問題アプリ — 問題データスキーマ

## 1. 問題オブジェクトの構造

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | number | 一意な整数（採番規則は §3 参照） |
| `category` | string | 章ID（§2 参照） |
| `difficulty` | `"A"` `"B"` `"C"` | A:基本 / B:標準 / C:応用 |
| `type` | `"choice"` `"ox"` | 4択 または 〇× |
| `classification` | string | セクション名（管理用） |
| `question` | string | 問題文（LaTeX可、§4参照） |
| `options` | string[] | 選択肢4つ / ox は `["〇","✕"]` |
| `answer` | number | 正解インデックス（0始まり） |
| `explanation` | string | 解説文（LaTeX可） |
| `image_url` | string | 画像なしは `""` |

## 3. ID 採番規則

- 本体ファイル（`p*.js`）の問題：`章番号+連番`
  - 例：p1_c1 → `101, 102...`　p1_c2 → `201, 202...`
- 追加ファイル（`p*_additional.js`）：`20000台 + 章番号 + 連番`
  - 例：p1_c1 追加 → `20101, 20102...`　p1_c5 追加 → `20501, 20502...`

> **⚠️ 依頼時に必ず開始IDを指定してください。**  
> 例：「IDは 20501 から始めて」

## 4. LaTeX 記法（JavaScript 文字列内）

バックスラッシュは `\\` と二重にエスケープする。

| 内容 | 書き方 |
|---|---|
| 変数 | `$v$` `$m$` `$a$` |
| ギリシャ文字 | `$\\theta$` `$\\omega$` `$\\mu$` |
| 単位 | `$\\text{m/s}$` `$\\text{m/s}^2$` `$\\text{kg}$` `$\\text{N}$` |
| 分数（大） | `$\\dfrac{1}{2}mv^2$` |
| ルート | `$\\sqrt{2gh}$` |
| 上付き / 下付き | `$x^2$` / `$v_0$` |
| 積（×） | `$\\times$` |
| ほぼ等号（≒） | `$\\fallingdotseq$` |
| ベクトル | `$\\vec{v}$` |

## 6. 出力フォーマット

新しい問題は **`p*.js` 内の `window.loadQuizData("partX", [...])` の配列に直接追記する**。
（旧方式の `p*_additional.js` / `window.P*_ADDITIONAL_QUESTIONS` は廃止。
アプリはこの形式を読み込まないため使用しないこと）

```javascript
// p1.js の配列末尾に追記する要素の例
    {
        "id": 20501,
        "category": "p1_c5",
        "difficulty": "A",
        "type": "choice",
        "classification": "等速円運動",
        "question": "問題文",
        "options": ["選択肢0", "選択肢1", "選択肢2", "選択肢3"],
        "answer": 0,
        "explanation": "解説文",
        "image_url": ""
    }
```

- ox問題の場合：`"type": "ox"`, `"options": ["〇", "✕"]`
- ID は既存の最大値の続きから採番する（重複厳禁）
